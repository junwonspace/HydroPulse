HydroPulse 운동 중 수분 손실량 추정 프로젝트 정리본
작성일 2026년 11월 25일

1. 프로젝트 목표와 범위

HydroPulse는 신체 특성, 운동 시간과 강도, 환경 정보를 이용하여 운동 한 회 동안 발한으로 손실된 수분량을 추정하는 회귀 모델을 개발한다. Random Forest Regressor와 XGBoost Regressor를 동일한 조건에서 비교하고, SHAP으로 예측에 기여한 변수를 설명한다.

주요 출력은 Sweat_Loss_L(세션별 추정 발한 손실량, L)이며, 보조 출력은 Sweat_Rate_L_per_hour(시간당 발한량, L/h)이다. 체중 변화로 만든 정답도 측정 오차가 있는 근사값이다. 발한 손실량, 소변 등을 포함한 전체 수분 손실량, 음료 섭취를 반영한 순수분 부족량은 서로 다른 개념이다. 본 프로젝트의 1차 목표는 발한 손실량으로 한정한다. 이 값을 그대로 권장 음수량으로 표시하지 않는다.

현재 단계는 데이터 확인과 실험 설계이다. 손실량 모델 학습이나 실제 성능 평가는 수행하지 않았으며, 아래의 계산 예시는 모델 성능이 아니다.

2. 첨부 CSV 실제 확인 결과

확인 파일: gym_members_exercise_tracking.csv
데이터: 973행, 15열
빈 문자열 또는 공백 기준 결측 셀: 0개
주의: 빈 셀이 없다는 사실은 측정값의 정확성, 실제 수집 여부 또는 데이터 대표성을 보장하지 않는다.

아래는 원본에서 확인한 정확한 열 이름과 활용 방안이다.

01 Age: 나이. 기본 신체 특성 후보.
02 Gender: 성별 범주. 범주형 입력 후보이며 집단별 오차도 점검.
03 Weight (kg): 체중. 핵심 후보. 기존 값이 운동 직전 측정값인지는 확인 필요.
04 Height (m): 신장. 체격 정보 후보.
05 Max_BPM: 최대 심박수. 해당 기록의 집계 방식과 측정 구간 확인 필요.
06 Avg_BPM: 평균 심박수. 운동 강도 후보.
07 Resting_BPM: 안정 시 심박수. 개인 기초 특성 후보.
08 Session_Duration (hours): 운동 시간. 누적 손실량 추정의 핵심 후보.
09 Calories_Burned: 소모 칼로리. 장치 추정 방식과 예측 시점의 이용 가능성 확인 필요.
10 Workout_Type: 운동 유형. 범주형 입력 후보.
11 Fat_Percentage: 체지방률. 신체 구성 후보.
12 Water_Intake (liters): 기록된 수분 섭취량. 손실량 정답으로 사용 불가.
13 Workout_Frequency (days/week): 주간 운동 빈도. 운동 습관 후보.
14 Experience_Level: 운동 경험 수준. 코드의 의미를 데이터 설명서에서 확인.
15 BMI: 체질량지수. 체중·신장과 정보가 중복되므로 포함 여부를 검증.

CSV에는 참가자 ID, 세션 ID, 측정 날짜, 운동 전후 체중 쌍, 세션 중 소변량, 온도, 습도가 없다. 따라서 이 CSV만으로 발한 손실량 정답을 구성하거나 참가자 단위 분할을 보장할 수 없다.

Water_Intake의 기록 기간이 하루인지 운동 세션인지, 직접 측정인지 자기보고인지도 파일만으로 확정할 수 없다. Water_Intake를 정답으로 학습하면 섭취 행동을 예측하는 별도 모델이 된다. 그 점수를 발한 손실량 예측 성능으로 보고해서는 안 된다. 기존 CSV는 전처리와 모델 비교 절차를 연습하는 데 활용하고, 본 실험은 손실량 정답을 갖춘 별도 측정 데이터로 진행한다.

3. 운동 전후 측정으로 정답 구성하기

다음의 체중 기반 근사식을 사용한다.[1]

Sweat_Loss_L ≈ (Pre_Weight_kg − Post_Weight_kg) / ρ
               + Fluid_Intake_L − Urine_L

ρ는 물의 밀도이며 약 1 kg/L로 둔다. 이 가정에서 체중 차이 1 kg을 약 1 L로 환산한다. Fluid_Intake_L은 반드시 두 체중 측정 사이에 실제로 마신 음료량이고, Urine_L도 같은 구간에 배출한 양이다. 기존 Water_Intake를 이 항목으로 대체하지 않는다.

Sweat_Rate_L_per_hour = Sweat_Loss_L / Duration_hours
운동 시간이 0보다 큰 유효 세션에만 적용한다.

계산 예시: 운동 전 70.0 kg, 운동 후 69.4 kg, 섭취 0.5 L, 소변 0.1 L, 운동 1시간이면 추정 발한 손실량은 0.6 + 0.5 − 0.1 = 1.0 L이고 발한율은 1.0 L/h이다. 체중 감소 0.6 kg과 발한량 1.0 L는 같지 않다. 이는 설명용 가상 측정 사례이다.

측정 절차 제안
• 같은 저울을 사용하고 저울의 분해능과 교정 상태를 기록한다.
• 운동 전후에 같은 복장 조건을 유지하고, 운동 후 피부의 땀을 닦는다. 젖은 옷이 체중에 포함되면 손실량을 작게 추정할 수 있다.
• 운동 후 체중은 가능한 한 신속히 측정한다. 종료 후 체중 측정 전 음료를 마셨다면 섭취량에 포함한다.
• 음료 용기 전후 무게 또는 계량값으로 실제 마신 양을 기록한다. 흘리거나 몸에 부은 물은 제외한다.
• 소변량은 같은 측정 구간 전체에서 수집한다. 실제 배뇨가 없었던 0과 미측정을 구분한다.
• 음식 섭취, 구토 등 단순식에 포함되지 않은 질량 변화는 별도로 기록하고 해당 세션의 포함 기준을 정한다.

이 식은 호흡 및 대사에 따른 질량 변화 등을 완전히 분리하지 않는다. 특히 장시간 운동에서는 오차가 커질 수 있다. 따라서 정답 명칭을 ‘측정 기반 추정 발한량’으로 유지한다. 음수 정답이나 극단값은 자동으로 0으로 바꾸지 말고 기록, 단위, 계측 오류를 점검한다.

4. 새 데이터 수집 구조와 입력 변수

한 행은 참가자 한 명의 운동 한 세션으로 정의한다.

정답 구성 필수 항목
• Participant_ID, Session_ID, Start_Time, End_Time
• Pre_Weight_kg, Post_Weight_kg
• Fluid_Intake_L, Urine_L, Duration_hours
• 측정 장비, 측정 누락 여부, 품질 점검 메모

모델 입력 후보
• 운동 전: 나이, 신장, 운동 전 체중, 안정 시 심박수, 체지방률, 운동 경험
• 운동 정보: 운동 종류, 경과 시간, 관측 구간의 평균·최대 심박수
• 환경: 온도(°C), 상대습도(%), 실내외 여부
• 선택 확장: 속도, 케이던스, 의복, 열 적응 상태. 운동 유형에 맞게 수집한다.

운동 종료 후 세션 총량을 추정하는 모델과 운동 중 실시간 모델은 입력 시점이 다르다. 실시간 예측에는 그 시점까지 관측한 정보만 사용한다. 운동 전체 평균 심박수, 최종 운동 시간, 종료 후 칼로리를 미리 사용하면 미래 정보가 누출된다. 전체 세션 정답만으로 중간 시점 누적 손실량의 정확도를 입증할 수도 없다. 실시간 누적량 검증은 별도의 구간 측정 설계가 필요하다.

Post_Weight_kg, 체중 감소량, 계산된 Sweat_Loss_L은 학습 입력에서 제외한다. 정답 계산용 섭취량·소변량도 초기 모델에서는 제외하고 측정용으로 보관한다. 운동 전 체중은 예측 시점에 관측 가능하므로 입력으로 사용할 수 있다. 전후 체중과 섭취·소변량이 모두 있는 세션은 식으로 직접 계산할 수 있고, AI의 목적은 이런 종료 후 측정 없이 손실량을 추정하는 데 있다.

5. 모델 비교 계획

Baseline
학습 데이터의 평균을 출력하는 DummyRegressor와 중앙값을 출력하는 모델을 함께 둔다. MAE 기준에서는 중앙값 기준선이 특히 유용하다. 손실량 데이터가 확보되면 학습 데이터의 평균 발한율 × 운동 시간이라는 간단한 기준선도 비교할 수 있다.

Random Forest Regressor
여러 트리를 서로 다른 표본과 변수 조합으로 학습하고 예측을 평균한다. 비선형성과 변수 간 상호작용을 다룰 수 있다. 주요 조정 대상은 n_estimators, max_depth, min_samples_leaf, max_features이다. 깊이와 잎당 최소 표본 수를 조절해 과적합을 관리한다.[2]

XGBoost Regressor
트리를 순차적으로 추가하며 목적함수의 오차를 줄이는 부스팅 모델이다. 주요 조정 대상은 n_estimators, learning_rate, max_depth, min_child_weight, subsample, colsample_bytree, reg_alpha, reg_lambda이다. 초기 목적함수는 reg:squarederror로 두되 모델 선정은 검증 MAE로 수행할 수 있다. 조기 종료에 최종 테스트셋을 사용하지 않는다.[3]

공정한 비교를 위해 두 모델의 입력 변수, 데이터 분할, 검증 폴드, 탐색 예산을 동일하게 유지한다. RandomizedSearchCV 등의 탐색 횟수는 사전에 정한다. XGBoost가 항상 더 좋다고 가정하지 않고 검증 결과로 선택한다. 정확도가 유사하면 예측 시간, 모델 크기, 유지관리 부담도 고려한다.

6. 전처리와 데이터 분할 및 검증

전처리
단위 통일, 숫자형 변환, 중복 기록, 불가능한 값, 센서 오류를 점검한다. 범주형 입력은 원핫 인코딩 등 일관된 방식으로 변환한다. 수치 결측값 대체와 범주 인코딩은 각 학습 폴드에서만 학습하는 Pipeline에 넣는다. 트리 모델에는 일반적으로 표준화가 필수는 아니다. 정답 구성에 필수인 측정값이 누락되면 임의로 보간한 정답을 사용하지 않는다.

권장 검증 설계
1) 새로운 사용자에 대한 일반화를 평가할 때는 참가자의 약 20%를 최종 테스트용으로 먼저 분리한다. 같은 참가자의 세션은 학습과 테스트에 동시에 들어가지 않게 한다.
2) 나머지 참가자에서 GroupKFold 5개 폴드로 모델과 하이퍼파라미터를 선택한다. 참가자가 적으면 가능한 폴드 수로 줄인다.
3) XGBoost 조기 종료용 데이터는 각 폴드의 학습 부분 안에서 별도로 확보한다. 해당 폴드 평가용 데이터와 최종 테스트셋은 학습 결정에 사용하지 않는다.
4) 최적 설정과 학습 반복 수를 확정한 뒤 개발 데이터 전체로 재학습한다. 최종 테스트셋은 잠근 모델의 평가에만 사용한다.
5) 기존 사용자 미래 세션 예측이 목표라면 시간 순서 분할을 별도로 수행한다. 새 사용자 평가와 기존 사용자 미래 평가를 구분해 보고한다.

독립된 단일 세션 자료이고 참가자 중복이 없다고 확인된 경우에는 80:20 무작위 분할과 학습셋 내부 5-fold 검증을 사용할 수 있다. 기존 CSV 973행을 이 비율로 나누면 학습 778행, 테스트 195행이지만, 이는 손실량 정답이 없는 CSV의 연습용 숫자이다. 새 측정 데이터의 참가자 단위 분할에서는 행 비율이 정확히 80:20이 아닐 수 있다.[4]

교차검증 MAE 평균과 폴드 간 표준편차를 기록한다. 표준편차를 신뢰구간이라고 부르지 않는다. 필요하면 참가자 단위 부트스트랩으로 최종 테스트 지표 및 두 모델의 오차 차이에 대한 95% 신뢰구간을 구한다. 참가자 수, 세션 수, 제외 건수, 난수 시드, 라이브러리 버전, 분할 명단을 남긴다.

7. 평가지표와 해석

n은 평가 세션 수, y_i는 측정 기반 정답(L), p_i는 예측값(L), y_mean은 평가 정답의 평균이다.[5]

MAE = Σ|y_i − p_i| / n
평균 절대 오차. 단위는 L이며 낮을수록 좋다. 핵심 선정 지표로 사용한다. 예를 들어 MAE 0.15 L는 평균 절대 오차가 150 mL라는 뜻이며, 모든 예측이 ±150 mL 이내라는 뜻은 아니다.

RMSE = sqrt(Σ(y_i − p_i)^2 / n)
큰 오차에 더 민감한 지표. 단위는 L이며 낮을수록 좋다. 일부 세션의 큰 실패를 점검하는 데 활용한다.

R² = 1 − Σ(y_i − p_i)^2 / Σ(y_i − y_mean)^2
1에 가까울수록 좋다. 0은 해당 평가셋의 실제 평균을 항상 예측하는 것과 같은 제곱오차 수준이고, 음수도 가능하다. 정확도 백분율로 해석하지 않는다. 평가 정답이 모두 같으면 수학적으로 정의되지 않으므로 별도 표시한다.

MAPE(%) = 100 × Σ|(y_i − p_i) / y_i| / n
실제값 대비 상대 오차이다. y_i가 0이면 정의되지 않고 0에 가까우면 불안정하다. 주 지표로 사용하지 않는다. 필요하면 측정 분해능을 고려한 최소 정답 기준을 사전에 정하고, 기준을 넘는 표본의 MAPE와 포함·제외 건수를 함께 보고한다. 모든 표본의 MAE와 RMSE는 그대로 유지한다. scikit-learn의 MAPE 반환값은 비율이므로 백분율 표시에 100을 곱한다.

추가 진단 제안
• 평균 편향 = mean(p_i − y_i). 양수는 과대, 음수는 과소 추정.
• 절대 오차의 90백분위수와 운동 종류·시간 구간·환경별 MAE.
• 사용자 단위 MAE의 평균도 함께 제시하여 기록이 많은 사용자에게 평가가 치우치는지 확인.

허용 가능한 MAE는 정답 측정 오차와 서비스 목적에 따라 사전에 정한다. 근거 없이 R² 0.9 이상 등을 합격선으로 정하지 않는다.

8. 발표와 보고서 시각화 계획

실제 학습 후 동일한 평가 표본으로 아래 그림을 작성한다. 현재 단계에서는 성능 수치나 결과 그래프를 만들어 넣지 않는다.

① 모델별 MAE·RMSE 막대그래프
가로축 모델, 세로축 오차(L). 교차검증 평균과 폴드 간 표준편차 또는 테스트값과 부트스트랩 구간을 구분해 표시한다. R²와 MAPE는 단위가 달라 별도 그림이나 표로 제시한다.

② 실제값과 예측값 산점도
가로축 정답(L), 세로축 예측(L), 동일한 축 범위와 y=x 기준선. 높은 손실량 구간에서 과소 추정하는지 확인한다.

③ 잔차 그래프와 분포
가로축 예측값, 세로축 p−y, 잔차 0 기준선. 히스토그램으로 치우침과 큰 오차를 확인한다. 양수는 과대 추정이라는 부호 정의를 모든 그림에 통일한다.

④ 조건별 오차 상자그림
운동 종류, 시간 구간, 온도 구간 등에 따른 오차 분포와 표본 수를 표시한다. 소표본 집단의 순위를 과도하게 해석하지 않는다.

⑤ SHAP 요약·의존성·개별 설명 그림
전체 변수 기여도, 변수 값에 따른 예측 기여 변화, 한 세션의 예측 이유를 각각 보여준다.

9. SHAP 설명 방법

트리 모델에 적합한 TreeExplainer를 사용한다. 배경 데이터는 학습 데이터에서 선택하고 설명 방식과 표본 수를 기록한다. 동일 평가 표본을 사용하여 두 모델의 설명을 비교한다.[6]

회귀 출력이 L일 때 예측값은 기준값 + 각 입력 변수의 SHAP 값 합으로 설명할 수 있다. 양의 SHAP 값은 해당 예측을 기준값보다 높이는 기여, 음의 값은 낮추는 기여이다.

• 평균 절대 SHAP 막대그래프: 모델 예측에 크게 기여한 변수 순위.
• Beeswarm: 변수 값의 크기와 기여 방향 및 분포.
• Dependence plot: 운동 시간 등 한 변수와 SHAP 기여도의 관계.
• Waterfall: 한 세션에서 기준 예측이 최종 예측으로 바뀐 과정.

SHAP은 모델의 판단을 설명하며 생리적 인과관계를 증명하지 않는다. 체중·신장·BMI, 운동 시간·칼로리처럼 상관된 변수는 기여가 나뉘거나 설명 설정에 따라 달라질 수 있다. 원핫 인코딩된 범주들은 원래 변수 단위의 기여도를 합산해 해석할 수 있다. 최종 테스트 설명을 보고 모델을 반복 수정하면 테스트셋이 개발에 사용되므로 별도 재평가가 필요하다.

10. 실행 순서와 완료 기준

1단계: 기존 CSV로 변수 형식과 전처리 절차를 확인하고 데이터 출처 및 수집 정의를 확보한다.
2단계: 전후 체중·섭취·소변량을 같은 구간에서 측정하는 세션 기록지를 만들고 파일럿 수집으로 측정 오차를 점검한다.
3단계: 측정 기반 손실량 정답을 생성하고 참가자별 분할을 고정한다.
4단계: 기준선, Random Forest, XGBoost를 같은 조건에서 학습하고 검증 MAE로 선택한다.
5단계: 잠근 테스트셋에서 MAE·RMSE·R²·조건부 MAPE 및 편향을 보고한다.
6단계: SHAP과 오차 시각화를 작성하고 적용 가능한 운동·사용자·환경 범위를 명시한다.

완료 결과물은 정답 정의와 측정 기록, 재현 가능한 학습 절차, 기준선 포함 성능표, 오차 그림, SHAP 설명, 한계 정리로 구성한다. 새로운 사용자와 환경에서 기준선보다 개선되는지 확인한 뒤 적용 범위를 확장한다.
